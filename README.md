## What it does

1. **Setup wizard** — paste your API key, select your AI tools, auto-configure safety screening
2. **System tray** — real-time eval count, connection status, killswitch button
3. **EU AI Act compliance** — Art 12 record-keeping + Art 14 human oversight, automatic per seat

## Requirements

- An A2A Infrastructure account ([sign up free](https://a2ainfrastructure.com/auth/signup))
- An API key (starts with `a2a_`)
